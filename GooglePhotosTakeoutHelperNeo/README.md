# Google Photos Takeout Helper Neo

Run `UpdateGooglePhotosTakeoutHelperNeo.bat` in the project root to download the latest Windows build from:

https://github.com/Xentraxx/GooglePhotosTakeoutHelper_Neo

This folder should contain:
- `gpth.exe` — written by the update script
- `version.txt` — release tag
- `exiftool.exe` (optional) — place next to `gpth.exe` for full EXIF write

Do not commit the binaries.
